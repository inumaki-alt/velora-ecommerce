VELORA — Everyday, Elevated

VELORA is a minimalist e-commerce website featuring thoughtfully selected home, lifestyle, and everyday products. It provides a clean and user-friendly shopping experience through a modern design and interactive features.

## Project Links

- Live Website: https://inumaki-alt.github.io/velora-ecommerce/
- Figma Design: https://www.figma.com/design/R4NGXvpPEiKnfK8an5kLdn?node-id=0-1
- GitHub Repository: https://github.com/inumaki-alt/velora-ecommerce

## Features

- Product catalog with images, names, prices, and descriptions
- Product detail page
- Add to cart functionality
- Update product quantities and remove items
- Shopping cart subtotal calculation
- Favorites or wishlist functionality
- Product search
- Category filtering
- Product sorting
- Demo checkout with form validation
- Newsletter subscription form
- Responsive website layout
- Local storage for cart and favorites persistence

## Technologies Used

- HTML5
- CSS3
- JavaScript

## File Description

- index.html — Contains the website structure and content.
- styles.css — Handles the visual design, styling, and responsive layouts.
- app.js — Handles product data and interactive website functionality.
- README.md — Contains project information and documentation.

## How to Run the Project

1. Open or download the GitHub repository.
2. Download the project files.
3. Open "index.html" using a web browser.
4. Explore the VELORA storefront and its features.

## Project Purpose

This project was developed as an academic e-commerce website project to demonstrate front-end development skills, user interface design, responsive web development, and client-side JavaScript functionality.

## Important Note

VELORA is a front-end demonstration project. Checkout and newsletter features are for demonstration purposes only and do not process real payments or send actual newsletter emails.
